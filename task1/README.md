# Задание 1, вариант 3

Уравнение Пуассона в трапеции. Последовательная программа, OpenMP, MPI и MPI+OpenMP.

[Отчёт](report/report.pdf) · [Исходник LaTeX](report/report.tex)

## Запуск на Полюсе

Из каталога `task1`:

```bash
module load SpectrumMPI
make all
export RESULTS_DIR="$PWD/results/review-$(date +%Y%m%d-%H%M%S)"
bash submit.sh seq
bash submit.sh omp
bash submit.sh mpi
bash submit.sh hybrid
bjobs -a
```

Каждая команда `submit.sh` отправляет одно задание. Каждая конфигурация запускается пять раз. В задании OpenMP обе большие сетки дополнительно считаются последовательной программой и OpenMP с одним потоком на одном ядре.

Для отдельного сравнения MPI на одном процессе с последовательной версией есть `bash submit.sh mpi1`. Обе программы решают задачу на сетке 800×1200 по пять раз на одном логическом процессоре. Порядок запусков чередуется. При наличии `report/measurements.json` в `mpi1_comparison.txt` также выводится ускорение относительно одного MPI-процесса по сохранённым замерам на 32 процессах.

В каталогах `run1`–`run5` лежат результаты отдельных запусков. В `timings.txt` собраны минимум, медиана и максимум времени в секундах. В `openmp_speedup.txt` приведены ускорения относительно последовательной программы и OpenMP с одним потоком на том же узле. Привязка потоков перед замером записана в `*_placement.txt`.

Когда все четыре задания получат статус `DONE`, архив для отчёта можно собрать в той же сессии:

```bash
tar -czf task1-review.tar.gz \
    --exclude='400x600*_solution.dat' \
    --exclude='800x1200*_solution.dat' \
    -C "$RESULTS_DIR" .
```

Для профилирования MPI на одном узле выполните `make mpi-profile` и `bash submit.sh mpi-profile`. В одном задании пять раз проверяются 2 и 4 процесса на сетке 400×600, 8 и 16 процессов на сетке 800×1200. Скрипт собирает архив `mpi-phases.tar.gz`. Внутри лежат сводка `phase_summary.txt` и времена каждого процесса с привязкой к ядрам и сокетам в `rank_phases.txt`. Таймеры фаз охватывают итерационный цикл. Столбцы `exchange_x`, `exchange_y` и `allreduce` включают ожидание внутри вызовов MPI.
